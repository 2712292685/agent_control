# 安全说明

## 1. 最终安全手段

软件急停、lease、超时和里程计看门狗都是**辅助**手段。以下始终有效，优先级最高：

1. 实体遥控器急停/接管；
2. 断开机器狗电源；
3. 人保持安全距离，场地清空。

## 2. 本项目会自动做什么

- 30 Hz 持续发送 `SetRemote`（包括零）；SDK 没有自动重发/归零。
- 摇杆/PC 停止指令时归零；驱动退出时发送 5 次零包。
- 运动超时（默认 35 s）中止。
- 2 s 无位置/角度进度 → `no_progress` 中止。
- 方向与命令相反超过阈值 → `direction_mismatch` 中止。
- 单 tick 位置跳变 >0.5 m → `odom_jump` 中止。
- API TCP 断开 / 1 s 无 PING / lease 过期 → 立即取消运动并归零。
- Windows 停止轮询 job → API 停止 KEEP → 驱动 lease 过期停车。
- 急停锁存并重发 90 三次；解除必须显式 `ECLEAR` + 重新取得控制权 + 恢复姿态（默认 122）。

## 3. 本项目不会做什么

- 不会自动站立、自动切换姿态或自动恢复运动。
- 不会在运动失败后继续开环盲走。
- 不会绕过距离/角度/速度硬限制。
- 不会在没有控制权或急停锁存时发送运动。
- 不会在实现/自动化测试阶段向真机发送任何指令。

## 4. 真机首次测试清单

1. 空旷场地，地面干燥，周围无人/宠物/障碍物。
2. 机器狗电量充足、站稳，实体遥控器在手，操作者知道断电位置。
3. PC 连接机器狗热点，`/api/status` 显示：
   - `connected=true`
   - `in_control=true`
   - `motion_ready=true`
   - `estop_latched=false`
4. 先发送 `stand_up` / `balance_stand`，确认站稳。
5. 单轴小幅度：
   - 前进/后退 0.1–0.2 m；
   - 左/右平移 0.1–0.2 m；
   - 左/右转 10–20°。
   发现方向不对，立即停下，调整符号参数，不要继续加大幅度。
6. 测试 `/api/stop` 在运动中止。
7. 测试急停：`/api/estop` → 机器狗趴下/软停；确认锁存；在安全前提下 `/api/estop/clear`，机器狗重新站立。
8. 低速下 kill 驱动进程，观察机器狗是否在固件命令超时后停下；**不要假设它一定停**，实体遥控器保持在手。
9. 以上全部通过后，才逐步增加距离/角度，且始终不超过参数硬限制。

## 5. 失败模式与处置

| 情况 | 处置 |
|---|---|
| 控制权被实体遥控器抢占 | 驱动归零并报 `control_lost`；用实体遥控器接管 |
| API/Windows 断开 | lease 过期自动停车；检查网络/进程 |
| 里程计不更新/跳变 | 驱动中止，报 `no_progress`/`odom_jump`；不要反复重试，先排查 |
| 机器人不动但命令已发 | 可能趴下/锁定/未取得控制权；查看 `motion_ready_reason` |
| 急停恢复失败 | 5 s 超时保持锁定；使用实体遥控器/断电 |
| 驱动进程崩溃 | 固件命令超时未验证；实体遥控器/断电是最可靠的 |

## 6. 网络与访问

- HTTP API 默认只监听 `127.0.0.1`。
- 如改为 `0.0.0.0`/热点地址，必须设置 `AGENT_CONTROL_TOKEN`，并只在可信热点使用；网页/API 没有用户账号体系。
- 不要把 token 写进配置文件、日志、截图或 git。
- 同一时间只运行一个 SDK 消费者（`read_state`、`control_demo`、`agent_control` 三选一）。
